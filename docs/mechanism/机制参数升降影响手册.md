# 机制参数对模拟的影响（逐项实测 · active.json）

> 文档索引见 [README.md](./README.md)。

> **读法**：下面不是「哪些参数显著」，而是 **每一个参数** 升高或降低后，仿真里对应侧面会怎样变。数据来自 `tools/param_impact_sweep.py`（机制层对照，无 LLM）。

## 怎么读每一行

| 列 | 含义 |
|----|------|
| 参数 | JSON 路径 |
| 观察侧面 | 探针盯住的模拟量（健康/复发/心情/潮汐等） |
| 升高时 | 把该参数代数调大后，模拟如何变 |
| 降低时 | 把该参数代数调小后，模拟如何变 |

共实测 **329** 个可升降叶子；跳过 12 个非数值项；健康探针 30 天；生成于 2026-08-15 19:02 UTC；原始数据 [`param_impact/sweep_results.json`](./param_impact/sweep_results.json)。
